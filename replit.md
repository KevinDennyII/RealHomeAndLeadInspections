# Overview

Static multi-page marketing site for **Rayville — Real Home + Lead Inspections, LLC** (Baltimore City & County rental compliance). Vanilla HTML/CSS/JS, deployed on Netlify.

# Site map

- `index.html` — Home / path chooser
- `first-time-investors.html` — New to renting roadmap + City/County packages
- `ongoing-compliance.html` — Ongoing landlords, packages, individual bookings
- `check-registration.html` — Lookup placeholders + property-details Netlify form
- `thanks.html` — Form success page

# Booking

Acuity Scheduling deep links (RayVilleEnterprises.as.me): LeadInspection, CityInvestorPackage, CountyInvestorPackage, Rental-Inspection, LicenseRenewal, BaltCityAnnualRegistrationFiling.

Annual Baltimore City registration filing is **$95** with optional **2yr MDE add-on $140**.
